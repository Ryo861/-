# ChatGPT用・介護実習記録の赤ペン描画

学校のPCではインストールも実行も不要です。このフォルダーのZIPと記録PDFを、ファイルの読み取り・Python実行に対応するChatGPTのチャットにアップロードします。アップロードだけで自動起動するものではありません。利用するチャットの実行機能、PyMuPDF（fitz）、Pillowの有無によって実行できない場合があります。本クラウドでの検証は通常のChatGPT全環境での動作保証ではありません。外部API、OCRサービス、追加の登録は使いません。

## 教員が送る指示の例

「ZIPを展開してREADMEを読み、同梱プログラムをPythonで実行してください。PDFを画像化し、手書き記録を読んでください。誤字・助詞・だ／である調・介護用語・具体性・振り返り・次回の行動を確認し、必要最小限の短い赤字を作ってください。行っていない行為を補わず、不明な文字や位置は保留してください。実習開始・終了と休憩を確認し、休憩を除いて450分未満なら指摘してください。矛盾した時刻は推測で直さないでください。example.jsonの形式で添削JSONを作り、render_redpenでPDFと確認画像を出力してください。画像を見て赤丸と文字の対応・重なり・文字化けを確認し、保留件数も報告してください。原本は変更しないでください。」

## Pythonでの手順

展開したフォルダーをPythonの検索パスに追加して実行します。

```python
from redpen import export_pages, render_redpen, check_minutes
images = export_pages('記録.pdf', '読み取り画像')
# ChatGPTが画像を読み、添削.json を作成する。Pythonは手書き認識しない。
report = render_redpen('記録.pdf', '添削.json', '添削済み.pdf', '確認画像')
print(report)  # 保留を確認。本文を外部ログへ送らない。
```

同じ出力名・画像名が存在すると停止します。再実行は新しい名前／フォルダーを使ってください。依存が不足している場合は処理を中断し、ChatGPT側で利用可能な実行環境を確認してください。学校PCでのインストールを要求しません。

## JSON仕様（version 1）

`corrections` 配列に各指摘を入れます。`page` は1始まり。`bbox` は表示されたページ画像全体を基準とする `[左,上,右,下]` の0〜1座標です。ページを切り抜いた画像で測定しないでください。PDFの回転後の見た目を基準にします。`original` は読めた元の文字、`replacement` は修正文字、`comment` は短い助言、`kind` は `underline` またはその他（赤い楕円）、`confidence` は位置の確信度0〜1です。位置不明は `bbox:null` にします。確信度0.85未満は描画しません。修正文字があればコメントより優先します。1指摘の表示は改行なし24文字以内です。

指摘をまとめる場合は、ChatGPTが関連する部分全体の矩形と短い共通コメントを1項目にしてください。Pythonは意味を理解して自動でまとめません。収まらない場合、原本を縮小したり一覧ページを追加したりせず保留します。保留結果は教員が確認してください。

## 配置と限界

元PDFを保持したまま赤い楕円／下線と文字を重ねます。日本語フォントを同梱・埋め込みし、見つからないと停止します。原本画像の暗い画素を検出し、対象の近傍でコメント全体が空白に入る場所を探します。4件以下は15pt、それ以上は12ptです。文字を小さくして詰め込みません。赤字同士は重ならない配置にします。

薄い鉛筆、画像のノイズ、複雑な罫線では空白判定に限界があります。罫線も障害として扱うため、空白があっても保留になることがあります。座標が誤っていれば赤丸も誤ります。確信度はAIからの申告であり、正確さの保証ではありません。実際の生徒の手書きPDFは未検証です。出力画像をChatGPTと教員が確認することが必須です。電子署名やPDF/Aの維持は保証しません。

最初は生徒1人につき1つのPDFを使ってください。生徒の自動分割や30人の自動添削は実装していません。複数人に使う場合は、入力PDFとJSONを生徒ごとに明示的に対応させ、別々の出力名と作業フォルダーで処理してください。

実習時間は `check_minutes('08:30','17:00',[('12:00','13:00')])` で確認できます。休憩なしと確認した場合だけ `[]` を渡します。未記載の休憩は `None`（要確認）。日跨ぎ・重複・範囲外は要確認で、自動修正しません。

## 検証

`python -m unittest discover -s chatgpt_redpen -v`（リポジトリ直下）または展開フォルダー内で `python -m unittest test_redpen -v`。合成PDF、4方向の回転、元ページサイズ／文字の保持、日本語出力、保留、上書き拒否、時間の境界をテストします。サンプルは実在する生徒の記録ではありません。

同梱フォントはBIZ UDゴシック、ライセンスはOFL.txtです。PyMuPDFおよびPillowは同梱していません。ZIPはいつでも再アップロードできます。学校の個人情報取り扱いルールとChatGPTの利用可否を確認したうえで使用してください。
