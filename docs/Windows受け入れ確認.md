# Windows実機でのフェーズA受け入れ確認

クラウドのLinuxでの合格と、Windows実機での合格は別です。実データを使う前に、合成サンプルで次を確認します。

## 環境を記録

ソースコード版では `setup_windows.bat` の最後にOS、Python、CPUコア数、空き容量、RAMが表示されます。GPUは使いません。Windows 11・64bit・RAM16GBの実機を優先し、Windows 10は別の互換性試験として扱います。

## インストール不要版での確認

- [ ] ReleaseのWindows portable ZIPを取得する（Code → Download ZIPではない）。
- [ ] すべて展開し、Python未導入のPCでPracticeRecordChecker.exeが開く。
- [ ] 管理者として実行せず、画面とPDF表示・保存ができる。
- [ ] `_internal` を含めフォルダー一式を保持する。
- [ ] Windows動作確認結果.jsonで自動チェックの結果を確認する。
- [ ] インターネットを切り、練習用PDFで下の機能確認表を試す。
- [ ] 学校端末のアプリ実行ポリシーで禁止されていないことを確認する。

## 確認表

- [ ] ZIPをすべて展開し、setup_windows.batが「準備完了」で終わる。
- [ ] start_windows.batで日本語画面が開く。
- [ ] 「練習用PDFを作成」で空フォルダーに2件を作成し、原本が表示される。
- [ ] ＋／−、スクロール、左右のペインの幅変更ができる。
- [ ] 開始7:55、終了16:45、休憩11:50〜12:35で485分・クリアになる。
- [ ] 開始8:00、終了16:14、休憩12:00〜12:45で449分・不足になる。
- [ ] 休憩空白では要確認になる。
- [ ] 原本の位置をクリックし、承認済みコメントを追加・更新・削除できる。
- [ ] 未承認コメントがPDFに出力されない。
- [ ] 位置不明コメントは原本に印を置かず末尾一覧に出る。
- [ ] 個別保存後、原本1ページ＋コメント1ページになり、番号・日本語・元画像が正しく表示される。
- [ ] 保存済PDFを外部PDF閲覧ソフトでも開き、拡大して原本の欠損・ずれ・文字化けがない。
- [ ] 元のファイル名・内容は変わらず、原本への上書きは拒否される。
- [ ] 2人分を一括保存して2つの個別PDFになり、コメントが他の人に混ざらない。
- [ ] 同名出力がある一括保存では、その人だけ失敗と表示される。
- [ ] 暗号化・破損PDFを投入して読込失敗になり、他のPDFは処理できる。
- [ ] 複数ページPDFで同一生徒の確認が出る。全原本ページを保持して一覧が末尾に付く。
- [ ] インターネットを切って、起動・原本表示・時間計算・保存ができる。
- [ ] check_windows.batで19テストが実行され、失敗・skippedがない。

確認日、OS、Python版、RAM、合否、現象を学校内に記録してください。実際のPDFでの試験は学校が許可した端末・保存先で行い、記録や名前を公開リポジトリへ追加しないでください。

フェーズBのOCR評価は、未添削の匿名サンプルと教員の正解データを用意してから別途行います。今回の合成サンプルはOCR精度評価用ではありません。
