介護実習記録チェッカー インストール不要版（Windows 64bit）

Pythonのインストール、setup_windows.batの実行は不要です。

1. GitHubのReleasesから practice-record-checker-windows-portable.zip を保存します。
   Code → Download ZIPはソースコード用なので、この版とは別です。
2. 保存したZIPを右クリックし「すべて展開」を選びます。
3. 展開先のPracticeRecordCheckerフォルダーを開きます。
4. PracticeRecordChecker.exeをダブルクリックします。
5. 最初は「練習用PDFを作成」で空の練習フォルダーを選びます。
6. PDFを表示し、時刻を入力して計算。指摘箇所をクリックしてコメントを入力。
7. コメントを承認して「新規追加」。最後に「承認してPDF保存」を押します。

_internalなどのフォルダーも必要です。EXEだけを取り出さないでください。
WindowsのレジストリやPATHに登録しません。アプリ内にPythonを同梱しています。
アプリの分析・PDF保存時はインターネット接続不要です。
作業中のコメントや時刻は終了すると失われます。こまめにPDF保存してください。
手書きの自動読み取り・AI添削はフェーズAではありません。

学校の実行制限によりブロックされた場合は、管理者にアプリの許可を依頼してください。
署名付き製品としては配布していないため、Windows等が警告する場合があります。
セキュリティ設定を無効にしたり、制限を回避したりしないでください。

不要になった場合はアプリを終了し、展開したフォルダーを削除します。
自分で保存した原本や添削済PDFは別途、学校のルールに沿って管理してください。

詳細は docs/操作方法.md を参照してください。
