# はじめての操作方法（Windows）

このアプリは「手作業の添削をPDFにする」フェーズAの試作品です。紙の文字を自動で読んだり、自動添削したりはしません。

## 1. インストール

1. ZIPファイルを右クリックし、「すべて展開」を選びます。展開先は、例えば「ドキュメント」の中の「介護実習記録チェッカー」にします。
2. [Python公式ページ](https://www.python.org/downloads/release/python-3119/) の下の「Files」から **Windows installer (64-bit)** を選び、Pythonをインストールします。学校のPCでインストールが制限されている場合は管理者に依頼してください。
3. Pythonのインストール画面で「Add python.exe to PATH」をチェックします。通常のインストールには「Python Launcher」と「tcl/tk and IDLE」が含まれます。カスタムインストールの場合も有効にします。
4. 展開したフォルダーにある **setup_windows.bat** をダブルクリックします。黒い画面が開き、ライブラリを取得します。この準備のときだけインターネット接続が必要です。
5. 「準備完了」と出たら、キーボードのどれかのキーを押して閉じます。

Pythonはプログラムを動かす土台です。プログラムを書く操作は不要です。初回準備はPDFを扱わず、生徒の記録を外部送信しません。モデルは使わないのでモデル取得やAPIキーは不要です。

## 2. 起動

**start_windows.bat** をダブルクリックします。日本語の画面が開きます。初回準備後はインターネットを切った状態でも使えます。

最初は **練習用PDFを作成** を押し、空の練習用フォルダーを選んでください。架空の記録2人分が作られ、自動的に読み込まれます。既存の練習ファイルは上書きしないので、再び作るときは別の空フォルダーを選びます。配布ZIPの `sample_data` にも練習用PDFがあります。

## 3. PDF選択

**① PDFを追加（複数可）** を押し、ロイロノートから書き出したPDFを選びます。複数選択するときはCtrlキーを押しながらクリックします。

左の一覧から対象をクリックすると、中央に原本が表示されます。ファイル名が見切れるときは左一覧の横スクロールを使います。中央の **＋／−** で拡大・縮小でき、画像の端のスクロールバーで移動します。**◀／▶** でページを切り替えます。

1つのPDFを1人分として扱います。複数ページPDFでは、保存時に「全ページが同じ生徒か」を確認します。別の生徒が混ざっている場合はキャンセルし、元のツール等で生徒別PDFに書き出してから追加してください。自動分割しません。

## 4. 添削確認と入力

### 実習時間

右の欄に24時間制の時刻を入力して **実習時間を計算** を押します。

| 欄 | 練習用の入力 |
|---|---|
| 開始 | `7:55` |
| 終了 | `16:45` |
| 休憩開始 | `11:50` |
| 休憩終了 | `12:35` |

「正味485分（8時間5分）」「時間要件クリア」と表示されます。450分以上がクリアです。休憩時刻が分からないときは空白にして計算すると「要確認」です。45分の休憩を勝手に補いません。

休憩が複数回ある場合は、追加休憩欄に `14:00-14:10;15:00-15:05` のように入力します。休憩が本当にない場合だけ、「休憩なしを教員が確認した」にチェックし、休憩の時刻は空白にします。日跨ぎはフェーズAでは計算せず要確認です。

時刻を変更したら、必ずもう一度 **計算** を押します。計算せず変更すると以前の計算結果は保存対象から外れます。時間結果が未判定でもコメントの保存はできますが、時間要件を確認済みという意味にはなりません。

### 赤い番号とコメント

1. 中央の**原本の指摘箇所をクリック**します。青い十字が表示されます。
2. 右のコメント欄に、例えば「『実習開始』と記入しよう。」と入力します。
3. 内容を確認し、**このコメントを教員が承認** にチェックします。
4. **新規追加** を押します。原本に赤い丸番号が表示されます。
5. 別の指摘も同じように追加します。

承認せず追加したコメントは `未承認` と表示され、原本プレビューでは茶色い「？」になり、PDFには出力しません。

位置が分からない場合は **位置を外す／位置不明にする** を押してから追加します。原本には番号を置かず、末尾コメントページだけに出ます。コメント欄に「振り返り欄：」などを入れると分かりやすくなります。

修正するときは右の一覧からコメントを選択し、文章や位置を変えて **選択を更新** を押します。承認チェックも変更できます。不要なら **削除** を押します。入力欄だけに書いて追加・更新していない内容は保存されません。ページや生徒の切り替え前にも、追加・更新を済ませてください。

右の欄が画面に収まらないときは、その右端の縦スクロールバーで下へ移動します。

## 5. PDF保存

1. **④ 選択した生徒を承認してPDF保存** を押します。
2. 教員確認の画面で、原本・コメント・時刻を確認した場合に「はい」を押します。
3. 保存先フォルダーとファイル名を決めて保存します。初期名は `匿名001_日付_添削済.pdf` です。匿名番号は今回の読み込み順で、永続的な生徒IDではありません。
4. 保存後、中央が「保存済PDF」の表示に切り替わります。矢印で全ページと末尾のコメントページまで確認してください。
5. 問題がなければ、そのPDFをロイロノートから**手動で返却**します。

元の記録ページはすべて残り、承認済みコメントや時間結果があれば末尾に一覧ページが加わります。本文を消したり、長いコメントを本文に重ねたりしません。原本と同じファイルには保存できません。

出力名を変える場合は **匿名ID／表示名を変更** を使います。表示名の使用は教員が判断してください。入力ファイル名から氏名を推定しません。

全員分を保存する場合は、それぞれの原本・承認内容を確認してから **全員を確認して個別PDFを一括保存** を押し、出力フォルダーを選びます。同名出力がある場合はその人を失敗として表示し、他の人は続けて保存します。失敗した人を左の一覧から選び、個別保存で別名を指定すれば再実行できます。

**終了すると入力中のコメント・時刻は失われます。** 原本と保存済PDFは残ります。保存済PDFを再び読込んでも、編集状態やコメント一覧は復元されません。修正する場合は元の原本から作り直します。

## うまく動かないとき

| 状況 | 対処 |
|---|---|
| Pythonがないと表示される | Python 3.11の64bit版とPython Launcherを入れ直す |
| 初回準備が失敗する | インターネット接続や学校の通信制限を確認し、setup_windows.batを再実行 |
| 画面が開かない | setup_windows.batの「準備完了」を確認。エラー画面を学校の担当者に見せる |
| PDFを読めない | 破損・暗号化を確認し、ロイロノートでPDFを書き出し直す |
| 要確認になる | 時刻・休憩の空白、逆順、重複、範囲外、日跨ぎを確認する |
| 保存できない | 原本とは別名にする。保存先が書込可能か、PDFが別アプリで開かれていないか確認する |
| 一括保存で失敗した | 同名出力や表示名の重複を確認し、対象を選んで別名で個別保存する |

実データをGitHubやこのチャットへ送る必要はありません。最初は合成サンプルで試してください。
